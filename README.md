# Telegram 私聊机器人托管平台

一个部署在 Vercel 上的**开放式自助托管平台**：任何人只要把自己的 Bot Token 发给管理 bot，就能立刻拥有一个属于自己的**私聊转发机器人**，不用自己写代码、不用自己搭服务器。

> 访客给你的机器人发消息 → 机器人先验证对方是不是真人 / 广告号 → 通过后把消息转发给你 → 你直接回复那条转发消息，对方就能收到你的回复，全程看不到你的真实账号。

## 它能干什么

| 功能 | 说明 |
| --- | --- |
| 🤖 自助开通 | 任何人发自己的 Bot Token 给管理 bot，自动部署一个私聊转发机器人（每账号最多 10 个） |
| 🛡 动态人机验证 | 图片验证码（找不同 / 数数 / 按指令点 / 顺序记忆 / 动态口令），每题 90 秒，答错 3 次冷却 10 分钟，通过后 30 天免验证 |
| 🌐 网页真人验证 | 可选 Cloudflare Turnstile 网页验证，点一下按钮就能过（需配置 Turnstile 密钥） |
| 👀 观察期 | 验证通过后进入考察期，期间发链接类消息会计风险分，攒满直接拉黑；发满 2 条干净消息或时间到了自动解除 |
| 🚫 广告过滤 | 三档可调（宽松 / 标准 / 严格），自动拦截带链接、广告词、手机号的消息，并通知机主放行 / 加白 / 拉黑 |
| 📇 名单管理 | 白名单（永久信任）、黑名单、观察期名单，转发 bot 和管理 bot 两边都能管 |
| 🤖 AI 辅助（可选） | 机主自带 OpenAI 兼容接口：新用户通过验证后，AI 结合头像、昵称、简介和首条发言识别广告号，疑似时提醒机主；还可生成「今日消息总结」 |
| 📊 统计 | `/tongji` 看今日 / 累计联系人数和消息数；平台管理员可用 `/admin` 看全平台数据 |
| 🛠 自检修复 | `/fix` 一键检查 webhook 状态、重新绑定、重推命令菜单 |

**隐私说明**：平台默认不保存任何聊天内容。唯一例外是机主主动开启「AI 总结模式」后，当天已转发的消息会暂存 48 小时用于生成总结，关闭即不再记录。

- 管理 bot 的 Token：BotFather 给你的那串 `数字:字母`（形如 `123456789:AAE...`）
- 一个随机密钥：自己随便编一串 20 位以上的字母数字（比如用密码管理器生成），后面当 `SETUP_SECRET` 用

## 部署步骤（跟着做，10 分钟搞定）

### 第 1 步：把代码弄到你自己的 GitHub

1. 打开本仓库页面，点右上角 **Fork**，把仓库 Fork 到你自己的账号下。
2. 如果你没有 GitHub 账号，先在 [github.com](https://github.com) 注册一个（免费）。

### 第 2 步：去 Vercel 导入这个仓库

1. 打开 [vercel.com](https://vercel.com)，用 GitHub 账号登录。
2. 点 **Add New… → Project**。
3. 在列表里找到你刚 Fork 的 `telegram-multi-bot`，点 **Import**。
4. Framework Preset 保持默认（Other），**先别点 Deploy**，往下翻到 **Environment Variables**，按下面表格把变量填好再部署（也可以先部署、再到项目 Settings → Environment Variables 里补填，填完要重新部署一次才生效）。

### 第 3 步：创建 Upstash Redis，拿到连接信息

1. 打开 [upstash.com](https://upstash.com)，注册登录后点 **Create Database**。
2. 名字随便填（比如 `tg-bot-redis`），Region 选离你近的（比如新加坡 `ap-southeast-1`），类型选 **Regional**，点创建。
3. 进数据库详情页，翻到 **REST API** 区域，复制两样东西：
   - **UPSTASH_REDIS_REST_URL**（形如 `https://xxx.upstash.io`）
   - **UPSTASH_REDIS_REST_TOKEN**（一长串字母数字）
4. 把这两样填进 Vercel 的环境变量（见下表）。

> 也可以用 Vercel 自带的 Upstash 集成（项目里 Integrations → Upstash），集成会自动生成以 `KV_` 开头的变量，代码同样认得，不用再手动填。

### 第 4 步：部署

1. 环境变量填完后，点 **Deploy**，等 1 分钟左右，看到烟花 🎉 就是部署成功。
2. 记下你的项目域名，形如 `telegram-multi-bot-xxx.vercel.app`（部署成功页会显示；也可以在项目 Settings → Domains 里看到）。

### 第 5 步：激活管理 bot（只做一次）

在浏览器打开下面这个地址（把尖括号里的内容换成你自己的）：

```
https://<你的项目域名>/api/setupmanager?key=<你的SETUP_SECRET>
```

比如你的域名是 `telegram-multi-bot-abc.vercel.app`，SETUP_SECRET 是 `abc123`，就打开：

```
https://telegram-multi-bot-abc.vercel.app/api/setupmanager?key=abc123
```

看到返回里有 `"manager_bot": "你的管理bot用户名"` 和 Telegram 返回的 `ok: true`，就说明激活成功。

> 以后每次重新部署、或者管理 bot 突然没反应了，都可以重新打开这个地址再激活一次。

### 第 6 步：给管理 bot 发个消息试试

打开 Telegram，找到你的管理 bot，发 `/start`，看到欢迎语就说明平台已经跑起来了 🎉

## 环境变量表（复制粘贴用）

在 Vercel 项目 → **Settings → Environment Variables** 里添加，全部填完后点 **Redeploy** 重新部署一次。

| 变量名 | 必填？ | 填什么 | 去哪找 |
| --- | --- | --- | --- |
| `MANAGER_BOT_TOKEN` | ✅ 必填 | 管理 bot 的 Token | @BotFather 创建 bot 后给你的那串 `数字:字母` |
| `PLATFORM_ADMIN_IDS` | ✅ 必填 | 你的 Telegram 数字 ID（多个管理员用英文逗号隔开，如 `123456,789012`） | @userinfobot 查 |
| `SETUP_SECRET` | ✅ 必填 | 一串你自己编的随机字符（20 位以上字母数字，别用生日） | 自己编 |
| `UPSTASH_REDIS_REST_URL` | ✅ 必填 | Upstash 数据库的 REST URL | Upstash 控制台 → 数据库详情 → REST API |
| `UPSTASH_REDIS_REST_TOKEN` | ✅ 必填 | Upstash 数据库的 REST Token | 同上 |
| `TURNSTILE_SITE_KEY` | 可选 | Cloudflare Turnstile 的 Site Key | Cloudflare 控制台 → Turnstile → 你的站点 |
| `TURNSTILE_SECRET_KEY` | 可选 | Cloudflare Turnstile 的 Secret Key | 同上 |
| `API_BASE` | 可选（高级） | 自定义 Telegram API 地址，默认 `https://api.telegram.org`，不填就行 | 一般不用管 |

> 用 Vercel 的 Upstash 集成时，自动生成的变量名是 `KV_REST_API_URL` / `KV_REST_API_TOKEN`，代码也认，直接用就行，不用再手动建 `UPSTASH_` 开头的。

## 开通你的第一个转发机器人

1. 再去 [@BotFather](https://t.me/BotFather) 创建一个新 bot（`/newbot`），拿到它的 Token。
2. 打开你的**管理 bot**，把 Token 直接发给它（粘贴发送，不用加任何命令）。
3. 管理 bot 回一句 `✅ 部署成功！`，并告诉你新 bot 的用户名（比如 `@xxx_bot`），就开通好了。
4. 打开你的新 bot，发 `/start`，就能看到它的命令菜单。

**就是这么简单**：以后你的每个 Telegram 账号想各要一个独立的私聊机器人，都重复上面这 3 步；也可以把管理 bot 分享给朋友，让他们自己发 Token 开通，每人最多 10 个，数据互相隔离，谁也看不到谁的。

**注销机器人**：在管理 bot 里发 `/del`，按提示输入 bot 的数字 ID 或 @用户名。

## 使用方法

### 访客视角（别人找你时）

1. 访客打开你的转发机器人，发第一条消息。
2. 机器人先让对方做验证：答图片验证码（或点网页验证按钮）。
3. 验证通过后，对方的消息才会转发到你的 Telegram 账号上。
4. 你直接**引用回复**那条转发消息，对方就能收到你的回复，看不到你的账号。

### 机主视角（在你的转发机器人里）

| 命令 | 干什么 |
| --- | --- |
| `/start` `/help` | 看介绍和全部功能说明 |
| `/tongji` | 今日 / 累计联系人数、消息数、拦截数 |
| `/level` | 验证等级：🟢简易 / 🟡中等（默认）/ 🔴强力 |
| `/ad` 或 `/guanggao` | 广告过滤：宽松 / 标准（默认）/ 严格 |
| `/ai` | AI 辅助设置（接口 / Token / 模型 / 自定义 UA / 测试连接） |
| `/zongjie` | AI 生成今日消息总结（需先在 `/ai` 里开启总结模式） |
| `/baimingdan` | 白名单管理（永久信任的人） |
| `/heimingdan` | 黑名单管理 |
| `/guancha` | 观察期名单管理 |
| `/open` `/close` | 恢复 / 暂停接收陌生人消息（加白的人不受影响） |
| `/reset` | 清除某人的验证状态（回复对方的转发消息时发送） |
| `/cleanup` | 清理机器人发出的旧消息 |
| `/fix` | 自检修复：查 webhook、重新绑定、重推菜单 |

**快捷操作**：回复某条转发消息时直接发 `/bai`（加白）、`/hei`（拉黑）、`/jiehei`（解黑）、`/cd`（查对方状态）；每条转发消息上方也有按钮，点一下就能拉黑 / 加白。

### 管理 bot 视角

| 命令 | 干什么 |
| --- | --- |
| `/start` `/help` | 介绍和说明 |
| `/list` | 查看你注册的所有 bot（带今日 / 累计数据），点进去能管联系人、改设置、配 AI |
| `/del` | 注销某个 bot |
| `/admin` | （仅平台管理员）全平台今日 / 累计数据、各 bot 明细 |
| `/fix` | （仅平台管理员）管理 bot 自检修复 |

## 验证与观察期规则

### 验证等级（`/level` 切换）

| 等级 | 题目数 | 说明 |
| --- | --- | --- |
| 🟢 简易 | 1 题 | 无陷阱题，适合熟人多的场景 |
| 🟡 中等（默认） | 2 题 | 高风险账号（没用户名、新号、非 Premium 等）加到 3 题，第 3 题固定为顺序记忆；带陷阱题 |
| 🔴 强力 | 3 题 | 第 3 题固定为顺序记忆；带陷阱题；默认先走网页验证（Turnstile），答题做备选 |

**通用规则**：5 种题型（找不同 / 数数 / 按指令点 / 顺序记忆 / 动态口令），答案都在图片验证码里；每题限时 90 秒，1 秒内作答算无效，答错 3 次冷却 10 分钟；通过后 **30 天内不用再验证**；加白的人永久不用验证。

**网页验证**：在强力档或把验证方式切到「网页」时，新访客直接点按钮做 Cloudflare 真人验证，通过后进入强力观察期（48 小时，2 分拉黑）；网页验证链接 10 分钟内有效、一次性使用。

### 观察期（验证通过后的考察期）

| 等级 | 时长 | 攒满多少分直接拉黑 |
| --- | --- | --- |
| 🟢 简易 | 24 小时 | 8 分 |
| 🟡 中等 | 24 小时 | 5 分 |
| 🔴 强力 | 48 小时 | 2 分 |

**提前解除**：发满 **2 条干净消息** 或时间到了，观察期自动结束。观察期结束后进入 30 天计分周期：周期内攒满 20 分不会自动拉黑，只会提醒你一次，由你决定拉黑 / 加白 / 不管。

**风险分怎么算**：链接 +2、t.me 链接额外 +2、广告关键词每个 +2（上限 +4）、手机号 +2、@提及 +1、频道转发 +2、名片 +1；被广告过滤拦截的消息再 +2。

## 广告过滤

在转发机器人里发 `/ad` 切换三档：

| 档位 | 拦截线 | 效果 |
| --- | --- | --- |
| 宽松 | ≥ 5 分 | 只有很像广告的才拦 |
| 标准（默认） | ≥ 3 分 | 一条链接 + 一个广告词就拦 |
| 严格 | ≥ 2 分 | 一条链接就拦 |

被拦截的消息不会发给你，但会通知你一次，你可以点按钮 **放行**（只放这一条）、**加白**（以后都不拦他）、**拉黑**。已经加白的人不受广告过滤影响。

## AI 辅助（可选）

在转发机器人里发 `/ai` 打开设置面板（管理 bot 的 `/list` 里也能配）。需要你自己提供一个 OpenAI 兼容接口的 API Key（比如智谱、Gemini、AgentRouter 等）。

- **辅助观察**：新用户通过验证后，AI 结合他的头像、昵称、简介和首条发言判断是不是广告号，疑似时弹窗提醒你是否拉黑；只提醒，不拦截。
- **总结模式**：开启后，当天收到的消息会按人暂存（48 小时），发 `/zongjie` 让 AI 汇总今天谁联系了你、都说了什么事。
- **自定义 UA**：有些中转站的 Key 只认特定客户端（比如只认 `claude-cli`），点「设置自定义 UA」填上那个标识，AI 请求就会带上它；不填就按默认发送。
- **失效处理**：接口返回 401 / 403（比如 Token 错了或过期了），AI 辅助和总结模式会自动暂停并提醒你；更新 Token、测试通过后会问你要不要重新开启。

> 模型建议选带视觉能力的（辅助观察要看头像），比如智谱的 `glm-4.6v-flash`、Gemini 的 `gemini-3.5-flash-lite`；面板里「选择模型」能自动拉取模型列表，拉不到就手填模型名。

## 常见问题

**Q：管理 bot 发消息没反应？**
A：先打开激活地址再走一遍：`https://<你的域名>/api/setupmanager?key=<你的SETUP_SECRET>`。如果还是没反应，在管理 bot 里发 `/fix`，它会自查并告诉你原因（比如 Telegram 那边挂起了这个 bot ID，这种情况只能换个新 bot 当管理 bot）。

**Q：转发机器人没反应？**
A：在那个机器人里发 `/fix`，它会检查自己的 webhook 并重新绑定。

**Q：访问 `https://<域名>/api/manager` 只看到 `OK manager`，正常吗？**
A：正常。这是健康检查用的返回，说明服务在跑。真正的管理功能要在 Telegram 里用。

**Q：「选择模型」报错拉不到列表？**
A：有些中转站的模型列表接口不在标准路径上（比如 AgentRouter 的在 `/v1beta/models`），直接点「设置模型」手填模型名就行，不影响使用。

**Q：AI 测试连接报 401 / 403？**
A：Token 不对或过期了。去你的 API 提供商那重新领一个 Token，填进 `/ai` 再测。连续失败时 AI 功能会自动暂停，修好后会提示重新开启。

**Q：Turnstile 没配，强力档还能用吗？**
A：能用。网页验证不可用时会自动走答题验证，功能不受影响，只是少了「点一下按钮就能过」这个选项。

**Q：访客说验证图片看不到？**
A：让对方检查网络后重试；连续失败 3 次会冷却 10 分钟，机主也可以在名单里点「清除验证」让他重走一遍验证。

**Q：部署后改了环境变量，怎么生效？**
A：去 Vercel 项目 → Deployments，点最新一次部署旁边的 `⋯` → Redeploy，重新部署一次。

## 安全提醒

- **Token 和密钥只填在 Vercel 的环境变量里**，永远不要写进代码、不要截图发出来、不要提交到 GitHub。`SETUP_SECRET` 也一样，丢了就去 Vercel 里换一个新的再重新部署。
- 每个转发机器人的 webhook 都有独立的随机密钥，别人拿到你的项目域名也冒充不了你的 bot。
- 定期轮换 Token：BotFather 里 `/revoke` 可以吊销重发；换了之后要在管理 bot 里重新发一次新 Token 注册。
- 本项目免费额度内使用没问题，但不要拿去做违法或骚扰用途。
